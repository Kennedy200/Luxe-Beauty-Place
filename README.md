# Luxe Beauty Place — React website

A bespoke, responsive salon website built with React, Vite, CSS and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

## What's included

- Bespoke editorial art direction for Luxe Beauty Place
- Asymmetric image-led hero, animated service ticker and editorial feature section
- Interactive service list that preselects the appointment form
- Real salon imagery, locally optimized WebP assets and a gallery lightbox
- WhatsApp appointment request form (the salon confirms availability directly)
- 20% Tuesday offer enquiry, FAQ accordion, address, hours and directions
- Scroll-reveal motion, image hover movement, reduced-motion support
- Mobile navigation and persistent mobile booking action
- Keyboard focus states and responsive layouts
- 40 project-local design playbooks: 20 frontend engineering + 20 UI/UX
