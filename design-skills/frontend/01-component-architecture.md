# Component Architecture

Build small, composable components around user-facing sections and repeated patterns. Keep content data separate from rendering, name components by responsibility, and avoid abstractions that make a one-page site harder to follow. Extract a component when it has independent behaviour, repeated use, or meaningful complexity.
