# Form Engineering

Use native input types, required constraints, autocomplete hints, inputMode where useful, clear optional labels, and helpful error messages. Preserve user-entered values on validation failure and never imply a booking is confirmed unless the business confirms it.

## Apply it to Luxe Beauty Place

Review the relevant section, implement the principle in the actual interface, then verify it at desktop and mobile sizes. Record any business detail that still needs owner confirmation rather than inventing it.
